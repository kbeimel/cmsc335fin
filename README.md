Deployed App Link: [https://cmsc335fin.onrender.com/](https://cmsc335fin.onrender.com/)

App Description: Allows users to search artworks hosted by the Art Institute of Chicago, and provides basic information about the best match to the search query including the work itself, the artists, and some basic information about where or when it was created. Through integration with MongoDB, past search queries can be viewed and deleted by the user. This project is implemented using Node.js, Express.js, MongoDB, and HTML/CSS written from scratch, without the use of templates.
